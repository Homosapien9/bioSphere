## 1. Biosphere's own code and data

- **Code:** MIT License — see [`LICENSE`](LICENSE). Original work written for this
  project; no source file was copied from any external repository.
- **Shipped synthetic dataset** (`data/demo/`): generated by this repository's own

## 2. Ideas adopted from the three audited repositories (attribution, no code reuse)

Phase 1 (`docs/repository_audit.md`) audited these projects; the table below credits
the specific *design ideas* adapted into Biosphere. **No source code was copied
from any of them** — for licensing reasons (see §3) and because everything was
re-implemented from scratch against this project's requirements.

| Idea adopted | Adopted from | Where it lives in Biosphere |
|---|---|---|
| Provenance/synthetic labels on every data & prediction surface | **BioTwin** (HackRice 2026) — provenance enum on every ingested frame | `app.py` banners/badges; generator meta |
| Refuse-to-forecast semantics; report imputed inputs; "missing stays missing" | **BioTwin** — `modeling/forecast.py` refusal path, imputed-input disclosure | `src/wearable_loader.py` (loud masking), `app.py` (missing-input lists) |
| Robust personal baselines (median/MAD, sufficiency flags) | **BioTwin** — weighted robust baselines + model-card language | `src/personalization.py` |
| Error-visualization wording ("not a calibrated prediction interval") | **BioTwin** — `docs/MODEL_CARD.md` | `src/uncertainty.py`, `app.py` |
| Prequential / chronological evaluation discipline | **BioTwin** — immutable forecasts scored post-issuance | `src/evaluation.py` |
| Pydantic-typed FHIR R4 resource models with resourceType guards | **PatientPulse** (ScarletHacks 2026, MIT) — `backend/app/schemas/fhir_types.py` | `src/fhir_loader.py` (re-written for local bundles) |
| Ship-the-demo-data-with-the-repo fallback so demos never depend on a live service | **PatientPulse** — `fixtures/maria_static.json` + FHIR fallback banner | `data/demo/` shipped; app warns instead of crashing |
| Deterministic engine computes all numbers; LLM never does math (Biosphere: no LLM at all) | **PatientPulse** — `ai/engines/projection_engine.py` "NO LLM math" boundary | entire pipeline |
| Deterministic seeded synthetic-data adapter | **BioTwin** — `ingestion/adapters/synthetic.py` (`np.random.default_rng(42)`) | `src/data_generation.py` (seeded `default_rng`) |
| Slider-driven what-if over a fitted model, bounded with warnings | **VitalCast AI** — `Act2Simulator` UX (its implementation lacked range checks and silently imputed inputs — we fixed both) | `src/scenarios.py`, What-if tab |

## 4. Standards and external references (used, not redistributed)

- **HL7® FHIR® R4** — used strictly as a JSON data format for the synthetic bundles;
  no HL7-published artifacts are included in this repository. FHIR is a registered
  trademark of HL7.
- **LOINC, ICD-10-CM, RxNorm** — illustrative codes identify concepts in the
  synthetic bundles; code systems are referenced by URI, and no terminology files
  are redistributed. Codes are for demonstration only and must be validated before
  any real-world use.
- **Referenced datasets (not used in v1):** Synthea (Apache-2.0, verified), WESAD
  (UCI; license on the dataset's linked page), BIDSleep (PhysioNet; URL returned
  HTTP 404 at audit time). None of their data or code is included here.
